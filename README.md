# Bus Reservation System (Java)

A console-based Bus Reservation System developed in Java using Object-Oriented Programming concepts and file handling.  
This project allows administrators to manage buses and users to book or cancel seats efficiently.

## Features

### Admin Features
- Admin Login Authentication
- Add New Bus
- Remove Bus
- View All Buses
- Save Data

### User Features
- View Available Buses
- Check Seat Availability
- Book Seats
- Cancel Bookings
- View Booking History

## Files Used


busData.txt      -> Stores bus information
bookings.txt     -> Stores booking records




## How to Run

1. Open the project in IntelliJ IDEA / VS Code / NetBeans
2. Compile the Java files
3. Run the main class
4. Use the menu options to manage bookings
